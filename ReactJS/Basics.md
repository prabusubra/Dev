# ReactJS

  ## Hooks:-
  
  - **useState** - ***State Management***

  - **useReducer** -  ***Alternative Complex State Management***
    
  - **useEffect** - ***Side Effect and lifecycle***
    
  - **useContext** - ***Global State***

  - **useRef** - ***Access DOM Elements & Keep Mutable Values***

  - **useMemo** - ***Performance Optimization***

  - **useCallback** - ***Memoize functions***

  - **useLayoutEffect** - ***Run before paint***

  - **useDebugValue** - ***used for debugging purpose***
